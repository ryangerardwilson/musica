## Truth

Space is the pause key. Opening the menu means `showMenu` and leaving the download view so the cassette menu is what the operator sees. A failed or running download stays in that state.

## Color

Rain intensity uses teal through gold. The black-hole core is violet. Every visualizer row uses the same base color, so the field does not form horizontal bands. Failed downloads use red. Running downloads use mint. The selected download uses coral.

## Failure

If nothing is playing, space does not open the menu. Resume does not close the menu. Starting a track still closes it.
